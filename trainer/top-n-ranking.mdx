Top-N ranking is the fastest path from a pile of unread resumes to a confident shortlist. You upload any number of PDF or Word files; Resume Insight's AI (powered by GROQ LLaMA 4) reads each one and extracts a structured candidate profile covering skills, projects, internships, certifications, CGPA, and academic marks. When you're ready to shortlist, you request the top N candidates — the system scores every profile against a weighted rubric, optionally passes the results through an AI reranker for deeper evaluation, and returns a clean ranked list ordered by fit. You can even provide a plain-English instruction to guide the AI toward your specific hiring criteria.

---

## How It Works

<Steps>
  <Step title="Upload Resumes for AI Extraction">
    Send one or more PDF, DOCX, or DOC files to the upload endpoint. For each file, GROQ LLaMA 4 reads the raw text and extracts a structured JSON profile — name, email, skills, projects, internships, certifications, CGPA, and academic scores. Profiles are stored against a SHA-256 fingerprint of the file, so uploading the same resume twice is safe and will not create duplicates.
  </Step>
  <Step title="Request Your Top-N Shortlist">
    Call the top-N endpoint with how many candidates you want and an optional natural-language instruction. The system scores all stored profiles using a weighted rubric (skills, experience, projects, certifications, CGPA, and academic marks), then sends the candidates through an AI reranker (via OpenRouter) for a final relevance-aware ordering. The response delivers your ranked shortlist with scores, summaries, and key skills for each candidate.
  </Step>
</Steps>

### Scoring Weights

The base scoring step assigns points across six dimensions before AI reranking:

| Dimension | Max Points | How It's Calculated |
|---|---|---|
| Skills | 35 pts | 3.5 × number of skills (capped at 10) |
| Internships / Experience | 20 pts | 8 × number of internship entries (capped at 2.5) |
| Projects | 15 pts | 4 × number of projects (capped at ~4) |
| Certifications | 10 pts | 3 × number of certifications (capped at ~3) |
| CGPA | 12 pts | (CGPA / 10) × 12 |
| 12th Marks | 5 pts | (percentage / 100) × 5 |
| 10th Marks | 3 pts | (percentage / 100) × 3 |

After base scoring, the AI reranker adjusts the order based on overall profile quality, skill relevance, and any instructions you provide via the `command` parameter.

## Step 1: Upload Resumes

**`POST /admin/top_resume_filter/upload`**

Upload one or more resume files. For each file, the AI extracts a full structured profile and saves it to the database. Returns a per-file processing report.

**Supported formats:** `.pdf`, `.docx`, `.doc`

**Duplicate detection:** Each file is fingerprinted with SHA-256. If you upload an identical file again, the existing profile is updated in place — no duplicate entries are created.

**Extracted fields per profile:**

<Expandable title="View all extracted fields">
  | Field | Description |
  |---|---|
  | `name` | Candidate's full name |
  | `email` | Contact email address |
  | `contact` | Phone number or alternate contact |
  | `skills` | Flat list of all technical and soft skills |
  | `projects` | List of project titles or descriptions |
  | `internships` | List of internship entries |
  | `certifications` | List of certifications and courses |
  | `cgpa` | CGPA extracted from the education section |
  | `degree` | Bachelor's degree name |
  | `twelfth_marks` | 12th grade percentage or marks |
  | `tenth_marks` | 10th grade percentage or marks |
  | `achievements` | Awards, honors, and extracurricular achievements |
</Expandable>

### Example Request

```bash
curl -X POST http://localhost:8000/admin/top_resume_filter/upload \
  -H "Authorization: Bearer <your_trainer_token>" \
  -F "files=@john_doe.pdf" \
  -F "files=@jane_smith.docx" \
  -F "files=@alex_kumar.pdf" \
  -F "files=@priya_nair.pdf" \
  -F "files=@ravi_shankar.docx"
```

## Step 2: Get Top-N Candidates

**`POST /admin/top_resume_filter/top_n`**

Score and rank all previously uploaded profiles, then return the top N candidates. If you supply a `command`, the AI reranker uses it to adjust the ranking toward your stated preferences. Results include a rank, score, summary, key skills, and email for each shortlisted candidate.

### Request Body Parameters

<ParamField body="top_n" type="integer" default="5">
  The number of top candidates to return. Must be between 1 and 50. Example: `10`
</ParamField>

<ParamField body="command" type="string">
  A natural-language instruction that guides the AI reranker. Describe the type of candidate you want — the AI will prioritize profiles that best match your description. Example: `"Prefer candidates with React and Node.js experience and a CGPA above 8.0"`
</ParamField>

<ParamField body="use_openrouter" type="boolean" default="true">
  Whether to use the OpenRouter AI reranker for final ranking. Set to `false` to return results ranked by the base scoring rubric only (no AI reranking). Note: OpenRouter must be configured on the server for AI reranking to function.
</ParamField>

<ParamField body="filenames" type="string[]">
  An optional list of specific filenames to rank. When provided, only profiles matching these filenames are included in the ranking. When omitted, all profiles uploaded by your account are ranked.
</ParamField>

### Example Request Body

```json
{
  "top_n": 5,
  "command": "Prefer candidates with React and Node.js experience and a CGPA above 8.0",
  "use_openrouter": true,
  "filenames": [
    "john_doe.pdf",
    "jane_smith.docx",
    "alex_kumar.pdf",
    "priya_nair.pdf"
  ]
}
```

### Example curl

```bash
curl -X POST http://localhost:8000/admin/top_resume_filter/top_n \
  -H "Authorization: Bearer <your_trainer_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "top_n": 5,
    "command": "Prefer candidates with React and Node.js experience and CGPA above 8.0",
    "use_openrouter": true,
    "filenames": ["john_doe.pdf", "jane_smith.docx", "alex_kumar.pdf", "priya_nair.pdf"]
  }'
```

---

<Note>
  OpenRouter must be configured on the server (via the `OPENROUTER_API_KEY` environment variable) for AI reranking to work. If OpenRouter is not configured, the `/top_n` endpoint will return a 500 error. Contact your platform administrator if you see this error.
</Note>

<Tip>
  Write a specific `command` to get the most relevant shortlist. Instead of a vague instruction like `"Find good candidates"`, try something precise: `"Prefer candidates with machine learning or deep learning skills, at least 2 internships, and a CGPA of 8 or above"`. The AI reranker uses your instruction to reorder candidates accordingly.
</Tip>
