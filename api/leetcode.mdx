Resume Insight queries the LeetCode GraphQL API to retrieve a full snapshot of a user's competitive programming profile — breaking down problems solved by difficulty, identifying the languages they code in, and mapping out daily submission activity across the current year. The response also includes an AI-generated performance analysis that tells you, at a glance, where a candidate stands and what they should focus on next.

## Endpoint

```
GET http://localhost:8000/leetcode/analyze_leetcode/{username}
```

**Authentication:** Not required for this endpoint.

---

## Path Parameters

<ParamField path="username" type="string" required>
  The LeetCode username for the profile you want to analyze. This is the
  username shown in the URL of a LeetCode profile page
  (e.g., `https://leetcode.com/octocat` → `octocat`).
</ParamField>

---

## Request Example

<Tabs>
  <Tab title="cURL">
    ```bash
    curl -X GET \
      "http://localhost:8000/leetcode/analyze_leetcode/octocat"
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    username = "octocat"
    response = requests.get(
        f"http://localhost:8000/leetcode/analyze_leetcode/{username}"
    )
    data = response.json()
    print(data["profile"])
    print(data["analysis"])
    ```
  </Tab>
  <Tab title="JavaScript (fetch)">
    ```javascript
    const username = "octocat";

    const response = await fetch(
      `http://localhost:8000/leetcode/analyze_leetcode/${username}`
    );
    const data = await response.json();
    console.log(data.profile);
    console.log(data.analysis);
    ```
  </Tab>
</Tabs>

## Response

A successful `200` response returns a JSON object with three top-level keys.

<ResponseField name="profile" type="object">
  Core statistics scraped directly from the LeetCode profile.

  <Expandable title="profile fields">
    <ResponseField name="Username" type="string">
      The LeetCode username as returned by the LeetCode API.
    </ResponseField>

    <ResponseField name="Total_Solved" type="string">
      Total number of problems the user has solved across all difficulty levels.
    </ResponseField>

    <ResponseField name="Easy" type="string">
      Number of Easy-difficulty problems solved.
    </ResponseField>

    <ResponseField name="Medium" type="string">
      Number of Medium-difficulty problems solved.
    </ResponseField>

    <ResponseField name="Hard" type="string">
      Number of Hard-difficulty problems solved.
    </ResponseField>

    <ResponseField name="Ranking" type="number">
      The user's global ranking on LeetCode based on contest and problem-solving
      performance.
    </ResponseField>

    <ResponseField name="Reputation" type="number">
      The user's community reputation score, earned through contributions to
      LeetCode discussions and solutions.
    </ResponseField>

    <ResponseField name="Rating" type="number">
      The user's star rating on LeetCode, reflecting contest performance.
    </ResponseField>

    <ResponseField name="Languages" type="array">
      An array of programming language names in which the user has solved at
      least one problem (e.g., `["Python3", "Java", "C++"]`).
    </ResponseField>

    <ResponseField name="activity_graph" type="array">
      Daily submission data for the current calendar year. Each entry is an
      object:
      - `date` (string, `YYYY-MM-DD`) — the submission date
      - `count` (number) — number of accepted submissions on that date
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="analysis" type="object">
  A computed performance assessment generated by Resume Insight's scoring
  engine.

  <Expandable title="analysis fields">
    <ResponseField name="sentiment" type="string">
      An overall performance label: `"positive"`, `"neutral"`, or `"negative"`,
      based on total problems solved and difficulty distribution.
    </ResponseField>

    <ResponseField name="reason" type="string">
      A human-readable explanation of the sentiment rating, including specific
      improvement suggestions when applicable.
    </ResponseField>

    <ResponseField name="metrics" type="object">
      Calculated metrics used to derive the performance score:
      - `problem_distribution` — breakdown as a formatted string, e.g.
        `"Easy: 30.0%, Medium: 45.0%, Hard: 25.0%"`
      - `total_problems` — total problems solved as a number
      - `languages_used` — count of distinct programming languages used
      - `difficulty_rating` — weighted average difficulty score
    </ResponseField>

    <ResponseField name="scores" type="object">
      Individual score components used to compute the overall rating:
      - `distribution` (number, 0–3) — how balanced the easy/medium/hard split is
      - `volume` (number, 0–3) — score for total problems solved
      - `difficulty` (number, float) — weighted difficulty of problems attempted
      - `languages` (number, 0–3) — breadth of programming languages used
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="activity_graph" type="array">
  A convenience copy of the daily submission activity array, also included
  inside `profile`. Each item has a `date` (string) and `count` (number) field.
  Sorted in ascending date order.
</ResponseField>

## Error Responses

All errors are returned with HTTP status `400` and a JSON body with an `error`
key.

<AccordionGroup>
  <Accordion title="Username not found">
    Returned when LeetCode has no account matching the supplied username.

    ```json
    {
      "error": "User octocat not found"
    }
    ```

    **Resolution:** Confirm the username by visiting
    `https://leetcode.com/<username>` in a browser. LeetCode usernames are
    case-sensitive.
  </Accordion>

  <Accordion title="LeetCode API unreachable">
    Returned when the LeetCode GraphQL endpoint returns a non-200 status, which
    may indicate temporary unavailability.

    ```json
    {
      "error": "Failed to access LeetCode for user octocat (Status: 503)"
    }
    ```

    **Resolution:** Wait a few minutes and try again. If the problem persists,
    check LeetCode's service status.
  </Accordion>

  <Accordion title="Response parsing failed">
    Returned when LeetCode's response structure is unexpected — typically caused
    by API changes.

    ```json
    {
      "error": "Failed to parse LeetCode response: ..."
    }
    ```

    **Resolution:** Contact Resume Insight support with the full error message.
  </Accordion>
</AccordionGroup>
