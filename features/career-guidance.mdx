Resume Insight provides two complementary AI-powered career guidance tools that work together to help you chart a clear path forward. The **Career Guidance Report** gives you a structured, comprehensive analysis of your strengths, skill gaps, learning paths, and project recommendations — all derived from your actual resume data. The **AI Chat Assistant** lets you ask follow-up questions and get personalized answers in real time, with your resume always in context. Together they replace the need for a career advisor for most early-stage job seekers.

## Career Guidance Report

The guidance report is a deep analysis of your resume that returns a rich structured document covering ten areas: your current technical skills with estimated proficiency levels, missing skills, learning path recommendations, project ideas, certificate guidance, role matching with gap analysis, weak skills to drop, recommended tech stacks, a career clarity summary, and a week-by-week improvement schedule.

**Endpoint:** `POST /guidance/generate`

Pass the `structured_info` object you received from your resume upload as the `resume_data` field. This is the parsed resume data — not the raw file.

**Example request:**

```bash
curl -X POST http://localhost:8000/guidance/generate \
  -H "Content-Type: application/json" \
  -d '{
    "resume_data": {
      "name": "Priya Ramesh",
      "skills": {
        "technical": ["Python", "React", "FastAPI", "MongoDB", "Git"],

        "area_of_interest": ["Web Development", "Machine Learning"]
      },
      "education": {
        "bachelor": {
          "degree": "B.E. Computer Science",
          "institute": "Anna University",
          "cgpa": "8.6"
        }
      },
      "projects": [
        {
          "title": "AI Resume Analyzer",
          "description": "Full-stack app for resume parsing and ATS scoring",
          "technologies": ["Python", "React", "MongoDB"]
        }
      ],
      "certificates": ["AWS Cloud Practitioner"],
      "internships": []
    }
  }'
```

## Role Roadmap

If you have a specific job title in mind, the role roadmap endpoint generates a step-by-step learning plan comparing your current skills against what the role requires, with phased milestones and project recommendations.

**Endpoint:** `POST /guidance/role-roadmap`

<ParamField body="target_role" type="string" required>
  The job title you want to work toward. Examples: `"Backend Developer"`, `"Data Scientist"`, `"DevOps Engineer"`, `"ML Engineer"`.
</ParamField>

<ParamField body="current_skills" type="array of strings" required>
  Your current technical skills as a list of plain strings. Pull these from your resume's `structured_info.skills.technical` array.
</ParamField>

<ParamField body="experience_level" type="string" default="fresher">
  Your current experience level. Accepted values: `"fresher"`, `"junior"`, `"mid"`. Defaults to `"fresher"` if not provided.
</ParamField>

**Example request:**

```bash
curl -X POST http://localhost:8000/guidance/role-roadmap \
  -H "Content-Type: application/json" \
  -d '{
    "target_role": "Backend Developer",
    "current_skills": ["Python", "FastAPI", "MongoDB", "Git", "HTML", "CSS"],
    "experience_level": "fresher"
  }'
```

## AI Chat Assistant

The AI Chat Assistant lets you ask any career question — and get an answer that takes your specific background into account. You can ask for skill gap assessments, interview tips, resume improvement suggestions, or career pivot advice. Attaching your resume data ensures the AI's answers are personalized to your actual situation, not generic advice.

**Endpoint:** `POST /ai/chat`

<ParamField body="query" type="string" required>
  Your question or request in plain English. Be as specific as possible for the most useful answer.
</ParamField>

<ParamField body="resume_data" type="object">
  Your resume's `structured_info` object from your last upload. Optional, but strongly recommended — without it, the AI cannot personalize its response to your background.
</ParamField>

**Example request:**

```bash
curl -X POST http://localhost:8000/ai/chat \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What skills should I add to my resume to get a backend developer role?",
    "resume_data": {
      "skills": {
        "technical": ["Python", "FastAPI", "MongoDB", "Git", "React"],
        "area_of_interest": ["Web Development"]
      },
      "projects": [
        { "title": "AI Resume Analyzer", "technologies": ["Python", "React", "MongoDB"] }
      ],
      "certificates": ["AWS Cloud Practitioner"]
    }
  }'
```

**Example response:**

```json
{
  "response": "Based on your current skills in Python, FastAPI, and MongoDB, you have a solid foundation for backend development. To strengthen your profile for backend developer roles, I recommend adding: 1) SQL / PostgreSQL — relational databases are expected alongside MongoDB in most production environments. 2) Docker — containerization is now standard in backend workflows and is a frequent interview topic. 3) Redis — caching knowledge is highly valued for APIs at scale. 4) Linux command-line basics — backend services run on Linux and interviewers often test this. 5) CI/CD fundamentals — setting up a basic GitHub Actions pipeline on one of your projects would demonstrate production awareness. Your AWS cert is a good differentiator — consider emphasizing it in your skills section."
}
```

## Caching Guidance

Career guidance results are cached per user account so you do not need to re-generate them on every visit to your dashboard. You can save a guidance result and retrieve it later using the following endpoints.

**Save guidance to your account:**

```bash
curl -X POST http://localhost:8000/user/guidance/priya.ramesh@email.com \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{ "guidance": { "..." } }'
```

**Retrieve cached guidance:**

```bash
curl http://localhost:8000/user/guidance/priya.ramesh@email.com \
  -H "Authorization: Bearer <your_token>"
```

The `GET` endpoint returns `{ "guidance": { ... } }` with your last saved guidance object. If no guidance has been saved yet, the `guidance` field will be an empty object. Use the dashboard's **Generate Guidance** button to create and auto-save new guidance whenever you re-upload a resume with new skills.

<Tip>
  The AI Chat Assistant works best when you pass your full `resume_data` from your most recent upload. You can copy the `structured_info` value from the `POST /user/upload_resume` response and include it in every chat request for consistently personalized answers.
</Tip>
